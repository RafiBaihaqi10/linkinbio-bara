# Link in bio Bara

Halaman statis (satu file, tanpa build). Isi: `index.html`, `bara.jpg`, `og-icon.png`.

**Ubah link:** edit array `LINKS` di bagian `<script>` paling bawah `index.html`.
- `utama: true` = kartu coral besar di atas, `stiker` = label kuning (contoh "TUTUP 4 NOV", hapus setelah lewat).
- `grup` = judul kelompok, `ikon` = magang | loker | cv | info | ig | tiktok.

**Online-kan:** seret folder ini ke app.netlify.com/drop (gratis), atau push ke GitHub Pages / Vercel. Pasang URL-nya di bio IG.
